# Scale Your Firm — website

A unified, responsive static website combining the three supplied design references:
- Home / overall lead and deal systems
- M&A, capital raise & debt advisory
- Deal intermediaries

## Preview locally
Open `index.html` in a browser, or run a local server from this directory:
```bash
python -m http.server 8000
```
Then visit http://localhost:8000.

## Included
- Unified navigation and shared visual language, keeping the original light editorial style and restrained navy/blue/green/gold accents.
- Audience-specific advisory and intermediary sections.
- Interactive workflow preview using sample data.
- Subtle animated node network background (disabled for reduced-motion preferences).
- Responsive mobile navigation and layouts.
- All booking CTAs link to https://cal.com/deepak-duodial/15min?overlayCalendar=true.

## Important
The workflow preview is illustrative only; it does not connect to a live CRM, send messages, execute NDA workflows or store leads. Real integrations require the relevant accounts, permissions, business rules and implementation. The two-week timing is described as a planning guide, not a guarantee.
